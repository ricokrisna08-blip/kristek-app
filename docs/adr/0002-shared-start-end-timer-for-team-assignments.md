# One shared Start/End timer per Tiket, not one per assigned Teknisi

A Tiket can be assigned to more than one Teknisi. We considered giving each assigned Teknisi their own Start/End button and photo requirement, so individual contribution to a multi-person job could be measured precisely — this was our initial recommendation during design. The owner rejected it in favor of a single shared Start/End button for the whole assigned team, with every team member receiving equal performance credit when the Tiket is marked Selesai. This trades individual-contribution accuracy for a much simpler mental model and UI (one clock, one photo pair per Tiket regardless of team size). Reversing this later — splitting the shared timer into per-Teknisi timers — would require reworking the Tiket state machine, the photo-upload flow, and the performance-report calculation, so it's recorded here rather than assumed obvious.
